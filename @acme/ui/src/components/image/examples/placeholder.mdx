### Placeholder

While the image is loading, `Image` fills the wrapper with a `Skeleton`. Pass
any node to `placeholder` to replace it, or `placeholder={null}` to render
nothing. The placeholder is absolutely positioned inside the wrapper, so it
inherits the `width` / `height` box.
