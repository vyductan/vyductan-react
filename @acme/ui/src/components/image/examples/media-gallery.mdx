### Media Gallery

`MediaGallery` is the whole surface in one component: `MediaMosaic` on desktop,
a swipeable carousel below `md`, and a shared `GalleryLightbox` opened from
either. It owns the open/index state, so callers pass data and nothing else.

Resize the preview past the `md` breakpoint to swap between the two layouts.
