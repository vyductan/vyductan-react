### ImagePreview Overlay

`ImagePreview` is the bare overlay used by `preview`, exposed on its own for
cases where the trigger is not an image — a button, a table row, a menu item.
It accepts arbitrary `children` and is controlled through `open` /
`onOpenChange` (uncontrolled if you omit both).
