# Radio

Radio button component for selecting a single option from a group. Built on top of Radix UI primitives and follows Ant Design API patterns.

## Examples

### Basic Usage

The simplest usage.

<ComponentSource src="radio/examples/basic.tsx" __comp__={RadioBasicDemo} />

### Button Style

The combination of `optionType="button"` and `buttonStyle="solid"` will render a solid button style radio group.

<ComponentSource
  src="radio/examples/button-style.tsx"
  __comp__={RadioButtonStyleDemo}
/>

### Color

Use `color` prop to set different colors for radio buttons. Available colors include `default`, `success`, `processing`, `error`, `warning`, and custom colors like `blue`, `green`, `purple`, `pink`, `teal`, etc.

<ComponentSource src="radio/examples/color.tsx" __comp__={RadioColorDemo} />

### Disabled

Radio unavailable state.

<ComponentSource
  src="radio/examples/disabled.tsx"
  __comp__={RadioDisabledDemo}
/>

### Tag

Use `optionType="tag"` for standalone chip-style options: unselected shows colored text on a transparent background, selected fills into a solid pill. Combine with the `color` prop per option.

<ComponentSource src="radio/examples/tag.tsx" __comp__={RadioTagDemo} />

### Pill

Use `variant="pill"` to keep the radio dot while styling each option as a chip: unselected shows colored text on a transparent background, selected fills into a soft colored pill. Combine with the `color` prop per option.

<ComponentSource src="radio/examples/pill.tsx" __comp__={RadioPillDemo} />
