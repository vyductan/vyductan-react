# AlertModal

A confirmation dialog component that displays an alert message with confirm/cancel actions. Built on top of the AlertDialog primitive components and follows Ant Design API patterns with Shadcn UI styling.

## Text selection

Title, description, and body text select and copy in one drag, same as Modal. The
alert box is short, so a drag usually leaves it — dragging out past the
bottom/right selects through to the end of its text, past the top/left back to
the start, instead of losing the selection. Footer button labels are treated as
chrome and never end up in the copy.
